# 포트폴리오 작성 자료

## 현재 사용할 수 있는 소개

> ROS 2 Humble과 TurtleBot3 Waffle Pi 시뮬레이션으로 실내 자동 매핑을 개발하고 있습니다. TF·센서·액션 상태를 분리 관측하여 정지 원인을 분석하고, 바퀴 기구학 측정과 충돌 윤곽을 검증했습니다. 직접 벽 추종에서 미탐색 경계의 정보 획득량을 평가하는 목표 선택기로 전환했으며, 경로 확인과 주행은 Nav2 액션으로 통합했습니다. House 전체 탐색과 복귀의 반복 검증은 진행 중입니다.

## 설명할 수 있는 기술적 판단

| 주제 | 보여줄 내용 | 자료 |
|---|---|---|
| 원인 분리 | Collision Ahead 로그를 시간 변환 실패와 실제 장애물로 구분 | TF 분석 원문·실제 관측 자료 |
| 측정 품질 | 접촉·헛돎이 섞인 기구학 추정값을 적용하지 않고 재측정 | 바퀴 감사 코드·품질 선별 검사 |
| 구조 개선 | 직접 벽 추종의 한계에서 Nav2 목표 선택으로 전환 | 개발 과정·현재 탐색기 |
| 목표 선정 | 미탐색 영역과 통행 가능성을 구분하고 가시성·예상 관측 면적 평가 | FrontierMap·회귀 자료 |
| 물리 모델 | 바퀴 축간 거리, 몸체 윤곽, DWB 충돌 검사 일관성 | 설정 생성기·검증 코드 |
| 검증 태도 | 단위 검사와 실제 Gazebo 주행의 검증 범위를 구분 | README·테스트·남은 과제 |

## 성공 후 추가할 자료

1. 동일 시작 위치에서 전체 탐색 → 종료 판단 → 출발점 복귀까지 이어지는 영상.
2. 최종 지도와 실제 House 형상을 비교한 이미지. 왜곡이 있다면 그대로 표시.
3. 여러 실행의 성공 횟수/전체 횟수, 탐색 시간·이동 거리·복구 횟수.
4. 제어·SLAM 설정과 소프트웨어 버전을 함께 보관한 재현 명령.
5. 변경 전후의 같은 조건 비교. 측정하지 않은 개선율은 쓰지 않기.

## 현재 주장하면 안 되는 결과

- House 전체 탐색·원점 복귀를 이미 검증했다는 표현.
- 단위 검사 통과를 실제 충돌 없는 주행 검증으로 바꾸는 표현.
- 바퀴 측정의 작은 시뮬레이션 잔차를 실물 위치 정밀도로 제시하는 표현.
- 축간 거리 수정 또는 사각 윤곽 변경만으로 지도 왜곡이 해결됐다는 표현.

현재 공개 후보는 소스·테스트·선별한 진단 자료·개발 기록입니다. 실제 지도 이미지·영상·반복 측정표는 확보 후 추가하세요. 개인정보나 내부 환경이 들어간 새로운 bag·스크린샷은 업로드 전에 확인합니다.
